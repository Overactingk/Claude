## 1. 배경 (왜 만드는가)

- 조직: 코비코 기술팀 **전장그룹** (특수목적·방산 차량 전장 설계). 관리자: 나대경M
- 현재 업무 전달 경로가 3개로 분산됨: ① 구두 ② 메신저 "업무전달방" ③ 개인 엑셀 "업무일정"
- 관리자가 "업무전달리스트" 엑셀(사내 공유폴더)에 종합 관리 중
- **문제점**
  - 개인 엑셀에만 적고 업무전달방에 안 올려 **누락** 발생 → 이중 관리
  - 업무전달리스트를 담당자들이 직접 들어가 수정 → **누군가 파일을 열고 있으면 저장 불가** (공유폴더 파일 잠금)
- 임시 대책으로 "개인 엑셀 + 파워쿼리 취합" 방식을 운영 예정. 이 웹앱은 그 **다음 단계(근본 해결)**.

## 2. 목표

- 업무 기록 장소를 **DB 하나**로 통일 (Single Source of Truth)
- 여러 명이 **동시에 실시간** 조회·수정 (파일 잠금 없음)
- 기존 엑셀 양식과 **같은 항목**을 유지해 팀원 학습 부담 최소화
- 보고용으로 **기존 엑셀 레이아웃 그대로 내보내기**

## 4. 데이터 항목 (기존 "전장 업무전달 리스트" 양식 기준)

| 항목 | 필수 | 설명 |
|---|---|---|
| 프로젝트 차종 | ○ | 예: KMPV, KMPV TCV, MNG, 비룡2, 대포병, IAG베어샤시, 교육, 기타 → **자유입력 + 기존값 자동완성** |
| 작성날짜 | ○ | 기본값 = 등록일 |
| 목표 | ○ | **변경 이력 보관 필수**. 화면에는 최초목표 → 현재목표 모두 표시 (기존 엑셀에서 셀 안에 줄바꿈으로 날짜를 누적하던 방식을 대체) |
| 완료 | | 완료 날짜. 입력되면 완료 처리 |
| 업무내용 | ○ | 여러 줄 텍스트 (기존 데이터에 줄바꿈·★·▶ 기호 많음 — 그대로 보존) |
| 담당 | ○ | **주담당 1명 + 협업자 0~N명** |
| 진행내용 | | 여러 줄. 가능하면 **날짜별 코멘트 이력** 형태 (누가/언제/내용) |
| 파일경로 | | 서버 경로 문자열 (`\\서버\...`) — 클릭 시 복사 |
| 비고 | | 자유 텍스트 |
| 출처 | | 구두 / 업무전달방 / 회의 / 메일 / 자체 (선택) |
| 요청자 | | 지시한 사람 (선택) |

- 모든 수정은 **변경 이력(audit log)** 남기기: 누가, 언제, 어떤 필드를, 이전값→새값

## 5. 기능 요구사항 (MVP)

### 필수
1. **로그인** — 사용자 선택 + 간단 비밀번호 (사내망 전용, 복잡한 인증 불필요)
2. **업무 목록** (메인 화면)
   - 기존 엑셀처럼 표 형태, 열 순서: 프로젝트 차종 / 작성날짜 / 목표 / 완료 / 업무내용 / 담당 / 진행내용 / 파일경로 / 비고
   - 필터: 담당자(주담당·협업 포함 여부), 프로젝트, 상태(진행중/완료/지연), 기간
   - 검색: 업무내용·진행내용 키워드
   - 정렬 기본값: 미완료 먼저 → 목표일 빠른 순
   - 색상: **빨강=지연**(미완료 & 목표일 지남), **노랑=3일 이내 마감**, **회색=완료**
3. **업무 등록/수정** — 누구나 등록 가능, 수정은 주담당·협업자·관리자만
4. **목표 변경** — 새 목표일 입력 시 이전 목표 자동 이력 저장
5. **현황 대시보드** — 담당자별: 전체 / 진행중 / 완료 / 지연 / 7일내 마감 / 협업 진행중
6. **엑셀 내보내기** — 기존 "전장 업무전달 리스트" 레이아웃
   - 1행 "■ 전장 업무전달 리스트" + 날짜, 2행 "일정" 병합(작성날짜·목표·완료 위), 노란 머리글(FFE699)
   - 목표 셀: 변경 이력이 있으면 `최초목표↵현재목표` 줄바꿈 표기
   - 담당 셀: `주담당↵협업자` 줄바꿈 표기
7. **초기 데이터 이관** — `seed_tasks.json` 47건 import
8. **입력 점검** — 작성날짜 없음 / 목표 없음 / 목표가 작성일보다 앞 / 프로젝트 없음 / 지연 → 목록 화면에서 표시

### 있으면 좋음 (2차)
- 진행내용 코멘트 스레드
- 주간 보고용 요약 (이번 주 완료 / 다음 주 마감)
- 첨부 대신 파일경로 여러 개
- 나중에 기존 "업체 관리 웹사이트" 프로젝트와 통합 가능성 (구조만 고려, 지금 구현 X)

## 6. 기술 조건

- **사내망 전용** (방산 업무 — 외부 클라우드·외부 CDN 사용 금지 가정. CSS/JS 라이브러리는 로컬 번들)
- 서버: 사내 Windows PC 1대에서 상시 실행 가정 → 팀원은 브라우저로 `http://PC주소:포트` 접속
- 권장 스택: **Python + Flask (또는 FastAPI) + SQLite**, 템플릿은 Jinja2, 엑셀은 openpyxl
  - 다른 스택이 더 적합하면 이유와 함께 제안할 것
- Windows에서 **더블클릭 한 번으로 실행**되는 배치파일(`start_server.bat`) 제공
- Windows 부팅 시 자동 실행 방법 안내 (작업 스케줄러)
- **자동 백업**: 매일 1회 SQLite 파일을 공유폴더로 복사 (경로는 설정 파일에서 지정)
- 설정값(포트, 백업경로, 관리자 계정)은 `config` 파일로 분리
- 화면은 PC 브라우저 기준(Chrome/Edge), 한글 UI

## 9. 기존 데이터 참고 (`seed_tasks.json`)

- 47건, 필드: `no, project, created_date, target_dates[], done_date, content, owner, collaborators[], progress, file_path, note`
- `target_dates`가 2개 이상이면 첫 값=최초목표, 마지막 값=현재목표
- `owner` = 기존 담당 칸의 첫 번째 이름(주담당), `collaborators` = 나머지
- 알려진 데이터 이슈: 작성날짜 없음 19건 / 목표 없음 1건 / 목표가 작성일보다 앞 1건 / 프로젝트 없음 1건 / 비고 "ㄴ" 1건(오타 추정) / 완료일 입력 1건뿐(실제 완료 여부 미확인)
  → import 시 그대로 넣고 "입력 점검"에 표시되게 할 것 (임의 수정 금지)
